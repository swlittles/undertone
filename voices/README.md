# Voices

Put RVC v2 voice models here, or use **Add voice…** in the app. Each voice can
live in its own folder with its `.pth` model and optional `.index` file:

```
voices/
  Deep Narrator/
    deep_narrator.pth
    added_IVF512_Flat_nprobe_1_deep_narrator_v2.index
```

Files in this folder are not committed to git.
